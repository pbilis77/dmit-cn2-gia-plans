## Pro、EB、T1 到底差在哪

三档的差别在线路，不在 CPU 和内存。

**Pro 是唯一给双向 CN2 GIA 的系列**，这也是它溢价的全部来源。洛杉矶的走法是电信、联通去程 CN2 GIA，移动去程 CMI，三网回程统一 CN2 GIA。注意"双向"这两个字：很多商家只优化回程，上传照样绕路，Pro 是去回都走优化线，做中转、跑上传的场景体感差别明显。

**EB 用三网 CMIN2 或 9929 回程**，电信走 AS9929 与 AS58807 负载均衡，联通 AS9929，移动 AS58807，IPv4 和 IPv6 双栈。线路等级比 CN2 GIA 低一档，代价是国内访问的稳定性和跳数，收益是同价位流量翻倍——TINY 档 1.5TB 对 1TB，MEDIUM 档 30TB 对 15TB。

**T1 是纯国际线路**，不对中国大陆做任何优化。它的卖点是流量超了限速不停机，限速阈值 100Mbps 到 500Mbps 不等，也不额外收费。

延迟方面，公开测评的数据大致是这样：洛杉矶 Pro 工作日白天 140–160ms，晚高峰偶尔到 180ms，没有出现大规模丢包；有测评从上海连 Pro TINY 平均约 145ms、北京约 160ms，三周 smokeping 丢包率基本在 0.1% 以下，晚 8 点到 11 点没有明显的延迟跳升。香港节点通常在 30–50ms，多份测评给的平均值在 39ms 上下，基本不丢包。这些都是第三方测评口径，你自己的线路（尤其移动宽带）可能落在区间之外。

## 香港和东京值不值得多花钱

香港的价格明显更贵。官网价格页上，香港和东京的 Premium 套餐与洛杉矶分开列出，同档位价格高出一截，页面展示的 MINI 档分别是 $72.90/月和 $79.90/月，流量配额反而更小。香港机房电信双向 CN2 GIA、移动和联通直连，30–50ms 的延迟是它贵的理由；东京走三网高速优化，面向亚太用户的项目更合适。

判断规则很简单：访问者主要在中国大陆南方、对延迟敏感到 50ms 和 150ms 有区别（比如实时协作、远程桌面、语音类应用），香港值这个钱。做网站、做中转、跑 API，140ms 和 40ms 用户基本感知不到，洛杉矶 Pro 的性价比高得多。

## 四个下单前必须知道的限制

**只支持 Linux，没有 Windows。** 需要 Windows 环境的直接排除，别指望工单能开例外。

**强制 SSH 密钥登录，不提供 root 密码登录。** 首次购买后要去后台下载密钥文件，再用 SSH 客户端连。安全性确实更高，但如果你是第一次用 VPS、习惯在面板上点开 root 密码直接登录，这一步会卡住你。不会配置的话，先在本地把密钥和客户端跑通再下单。

**IP 被墙可以免费换，但规则是每 15 天一次。** 超出这个频率或其它情况，$5 一次。对国内用户来说这是最实用的一条：被封了不用重新买机器，开工单换 IP 就行，但别指望一周换三次。

**流量超了限速，不断网、不额外收费。** Pro 和 EB 的 TINY、Pocket、STARTER 档超量后限到 4Mbps 不限量，MINI 和 MICRO 是 8Mbps，MEDIUM 10Mbps；T1 的限速阈值高得多，100Mbps 起。这意味着你不会有"账单突然多出一笔"的风险，但超量后的速度基本只能跑监控和轻量任务，重要业务还是要在面板里开流量告警。

还有一条容易忽略的：内网互通产生的流量同样计入套餐额度。香港到美国、日本到美国这些内网传输不额外收费，但流量照算，别以为走内网就免费。
